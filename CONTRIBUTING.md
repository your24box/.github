# 协作说明 · Contributing

感谢关注福州友宝电子科技有限公司（Fuzhou Youbao Electronic Technology Co., Ltd.）的工程展示。

Thank you for your interest in the engineering showcase of Fuzhou Youbao Electronic Technology Co., Ltd.

## 中文

本组织仓库主要用于客户审阅，默认不接受外部功能开发。我们更希望通过商务与技术对接来安排代码走读、接口联调或项目合作。

### 客户与合作伙伴

- 需要查看未公开仓库、演示环境或指定模块：请发邮件至 [suncai@24box.cn](mailto:suncai@24box.cn)，说明公司名称、项目背景与希望审阅的范围。
- 发现展示代码中的文档错误或构建说明问题：可在对应公开仓库开 Issue，请勿附带客户数据或生产配置。
- 安全相关发现：只通过 [SECURITY.md](SECURITY.md) 私下报告。

### 内部同事

- 对外展示的仓库在发布前去掉密钥、客户标识与内网地址。
- README 保持中英双语，结构与组织主页一致：先说明用途，再说明如何运行与如何联系。
- 不确定是否可公开时，先按私有仓库处理，并与商务或项目负责人确认。

### 行为与支持

请同时阅读 [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) 与 [SUPPORT.md](SUPPORT.md)。

## English

Repositories in this organization are primarily for client review. We do not take external feature contributions by default. Please arrange code walkthroughs, integration work, or project cooperation through business and technical contacts.

### Clients and partners

- For unpublished repositories, a demo environment, or a specific module: email [suncai@24box.cn](mailto:suncai@24box.cn) with your company name, project context, and the scope you need to review.
- For documentation or build-instruction issues in public showcase code: open an issue on that repository. Do not attach customer data or production configuration.
- For security findings: report privately only, as described in [SECURITY.md](SECURITY.md).

### Internal teammates

- Strip secrets, customer identifiers, and internal endpoints before publishing a showcase repository.
- Keep READMEs bilingual (Simplified Chinese and English), consistent with the organization profile: purpose first, then how to run and how to contact us.
- If publication is unclear, keep the repository private and confirm with the business or project owner.

### Conduct and support

Please also read [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) and [SUPPORT.md](SUPPORT.md).
